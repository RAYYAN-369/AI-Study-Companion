# 📚 AI Study Companion

An AI-powered Study Companion that helps students upload notes or syllabus documents and automatically generates structured study plans using Retrieval-Augmented Generation (RAG).

---

## 🚀 Features

- Upload PDF or Text Notes
- Automatic Document Parsing
- Intelligent Chunking
- Embedding Generation
- Qdrant Vector Database
- Semantic Search
- AI Study Plan Generation
- Responsive Web Interface
